Privacy Policy – Archivio YouTube

Last updated: 23 October 2026

← Home

Who operates this app

Archivio YouTube is a private tool operated by a single individual, the developer (GitHub user angelohavana54-tech). It is used only by its operator, with the operator's own Google account. It is not distributed and has no other users.

Google user data the app accesses

The app asks for Google Drive access (scope https://www.googleapis.com/auth/drive) on the operator's own Google account. It uses this access to create, list, read and update files in a single archive folder named "Archivio YouTube" in the operator's Google Drive, where it stores the documents it produces.

How the data is used and stored

  • Google Drive is used only as storage for the operator's own documents.
  • The authorisation token is stored only on the operator's own computer. The app has no server and no database of other people's data.
  • No Google user data is collected from anyone other than the operator.

Sharing

Data obtained through Google APIs is not sold, shared with or transferred to third parties, and is not used for advertising or to train AI models. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and revoking access

The operator can revoke the app's access at any time at myaccount.google.com/permissions. Deleting the stored token on the operator's computer also removes the app's access.

Contact

Questions about this policy: contact the operator through the GitHub profile angelohavana54-tech.
