Archivio YouTube

Archivio YouTube is a private, single-user tool. It is operated by one individual (the developer, GitHub user angelohavana54-tech) to keep a personal archive of study documents (PDF, DOCX and text files) created from public YouTube videos.

The documents are copied to one folder in the operator's own Google Drive, using Google Drive access that the operator authorises for their own account. The tool is not offered to other people and has no public sign-up.

See the Privacy Policy for how Google user data is handled.
